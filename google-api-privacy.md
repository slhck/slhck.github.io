This policy covers the Google Cloud project "gws personal", an OAuth application that Werner Robitza uses only for his own Google account.

### Purpose

The application gives command-line tools and a self-hosted assistant access to Werner Robitza's own Gmail, Google Calendar and Google Drive data. It is not offered to anyone else.

### Data Accessed

The application reads email, calendar events and Drive files of the signed-in account, and creates email drafts. It does not send email on its own.

### Storage and Sharing

Access tokens and data stay on devices and servers controlled by Werner Robitza. No data is sold, shared with third parties, or used for advertising. Data retrieved through Google APIs may be processed by AI models used by the assistant, only to perform tasks for the account owner.

The use of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

### Revoking Access

Access can be revoked at any time at [myaccount.google.com/permissions](https://myaccount.google.com/permissions).
